Glosario Técnico

Inyección SQL (SQLi): permite interferir en las consultas de una aplicación a su base de datos, eludiendo controles de acceso o extrayendo información confidencial.

XSS Reflejado: ocurre cuando la aplicación incluye datos no confiables en la respuesta sin sanitizar, ejecutando scripts en el navegador de la víctima.

Sentencias Preparadas: separan el código SQL de los datos del usuario, neutralizando por completo las inyecciones.

Sanitización de Entradas: filtra, escapa o limpia los datos ingresados antes de procesarlos o renderizarlos.
